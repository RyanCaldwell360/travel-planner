# Bundled assets

- `world.geojson`: Natural Earth, 1:110m admin-0 countries, public domain. Downloaded from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson . Terms: https://www.naturalearthdata.com/about/terms-of-use/ . Geography is illustrative and not a political boundary assertion.
- `images/mountains.jpg`: Start Bootstrap Grayscale's `dist/assets/img/bg-masthead.jpg` (mountain moodboard), sourced from https://github.com/StartBootstrap/startbootstrap-grayscale . Theme MIT license retained in `images/START-BOOTSTRAP-LICENSE.txt`; theme describes photographs as Unsplash imagery. Unsplash license: https://unsplash.com/license . This is decorative inspiration, not a verified photograph of any listed destination.
- `images/coast.jpg`: Start Bootstrap Landing Page's `dist/assets/img/bg-masthead.jpg` (sea moodboard), https://github.com/StartBootstrap/startbootstrap-landing-page . Same MIT theme / Unsplash imagery terms. Decorative inspiration, not location evidence.
- DM Sans and Libre Caslon Display: bundled via `@fontsource` packages, SIL Open Font License; license files in the dependency packages.
- Leaflet: BSD-2-Clause. Lucide icons: ISC. Package license metadata retained in installed dependencies.

Source-backed weather, if enabled, additionally requires Open-Meteo / Copernicus attribution as shown in the UI. Provider quote access and commercial rights require a separate provider account and current terms review.
